# مدیریت کانال‌ها بر اساس مدل و اصلاح جست‌وجو

- صفحهٔ `/fa/admin/channels`: انتخاب واحد SKU، چهار ویرایشگر کنار هم برای باسلام، دیجی‌کالا، اسنپ‌شاپ و تپسی‌شاپ. تغییر مدل از گارد مشترک همهٔ فرم‌ها عبور می‌کند و تغییر ذخیره‌نشده یا اقدام نامشخص را کنار نمی‌گذارد. SKU داخل هر فرم ثابت است؛ ذخیره، نسخه و عملیات هر بازار مستقل می‌مانند.
- تنظیمات عمومی هر بازار شامل درصد افزایش، هزینه‌ها و اتصال همچنان برای کل همان بازار است؛ اطلاعات عرضه، عنوان، تصاویر، دسته‌بندی و شناسه‌های بیرونی به مدل انتخاب‌شده مربوط‌اند. ذخیرهٔ اطلاعات هیچ اتصال یا همگام‌سازی بیرونی را فعال نمی‌کند.
- API کانال‌ها در انتشار تولید قبلی متصل نبود و 404 می‌داد. اکنون روترهای خصوصی و وب‌هوک با تنظیمات پیش‌فرض خاموش/پیش‌نمایش منتشر شدند. چهار کانال و 62 مدل منتشرشده روی سرور تأیید شدند. بدون نشست معتبر، API به‌درستی 401 برمی‌گرداند.
- جست‌وجو: `/search`، `/fa/search` و `/en/search` در اعتبارسنجی سرور، allowlist بخش کاربری و تشخیص صفحهٔ فروشگاه پشتیبانی می‌شوند. فرم سربرگ نشانی زبان جاری را می‌سازد. عبارت و فیلترها در URL حفظ می‌شوند؛ تطبیق واژه‌ها با یکسان‌سازی ی/ي، ک/ك، اعراب، فاصله و نیم‌فاصله انجام می‌شود.
- تست‌ها: 30 تست رابط/مسیر/قرارداد API، 5 تست PostgreSQL کانال‌ها، بررسی TypeScript و ساخت تولید موفق. هیچ کالا، سفارش یا وب‌هوک واقعی به بازارها ارسال نشد.
- انتشار: محیط محلی و `/srv/nilart/releases/variant-channels-20261102`؛ تصاویر قبلی با برچسب `before-variant-channels` حفظ شدند. فایل‌های .env و کلیدها تغییر نکردند.
