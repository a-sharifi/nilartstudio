# Operational reporting — 2026-10-19

FIN-11 is now a connected reporting workspace at `/admin/reports/inventory`, with `/admin/finance/inventory-value` and `/admin/reports/production` aliases. The existing panel, Yekan Bakh font, shared filters/tables and accessible icon actions are preserved in Persian and English. Desktop rows become mobile cards.

## Recorded source and historical scope

`/api/v1/admin/reports/{inventory|movements|production|waste}` reads immutable stock/production events. An explicit timezone-aware `as_of` is required; future times are rejected. Movements/waste also require an explicit `from_time`. Filters are echoed and checked by the client; applied filters remain in the URL through source navigation and browser back. Results and full-filter totals come from one SQL snapshot, independently of pagination. Empty later pages retain the complete totals.

Inventory uses the latest recorded movement version per position at the cutoff, including its quantity, value and threshold. Average cost is derived from that recorded balance, never today's resource rate. Quantities are grouped by kind and unit; sheets, pieces and other incompatible units are not summed. Low-stock filtering explicitly compares recorded on-hand quantity with a configured threshold. Unknown thresholds are not assumed to be zero. Unrecorded historical stock/cost is not invented. Historical reservation records do not exist yet, so the report explicitly withholds historical available/sellable quantities.

Stock movement and warehouse-waste reports retain original rows, reasons, signed quantity/value, original and correcting document IDs, source purchase/production/event IDs, and reversal status as of the cutoff. Waste corrections offset the original amount without deleting the physical history. Production abnormal losses remain in the production report; they are not also counted as warehouse waste.

Production uses the latest immutable batch event at the cutoff. It shows WIP, recorded actual total, healthy stock transfer, normal waste, abnormal damage/loss, complete/incomplete cost entries and healthy unit cost where meaningful. Normal waste remains absorbed in healthy output; abnormal loss is separate. WIP is explicitly not sellable. Estimates use rounded planned quantities and resource rates from the pinned recipe snapshot, with effective-date and IRT checks. Missing/invalid/other-currency rates produce unknown estimates. Variance is shown only for completed batches with complete costs and a known estimate; a draft/running batch is not presented as a final cost comparison. Current replacement rates do not rewrite old estimates or actual costs.

The admin dashboard now reads permission-controlled recorded inventory value, WIP, configured low-stock counts and incomplete-cost batch counts at one common displayed cutoff. Links carry that cutoff into their report. Errors show an unavailable state rather than zero. Private caches clear on identity changes and reject late responses.

## Exports and permissions

Reads require `finance.read`; exports independently require `finance.export`. Export-only staff can enter explicit report filters and download without acquiring report-read access. Operational source links independently require inventory or production permissions. A finance export page link exposes report exports to export-only staff. Main and alias navigation preserve the existing permission boundaries.

Each report has a bounded `/export?format=csv|xlsx` endpoint carrying the complete applied filters, source IDs, currency, dates, units, correction links and exact decimal strings. Exports cover all filtered rows rather than only the current page, with a 10,000-row limit that asks staff to narrow large reports. The existing financial-document export also supports XLSX with the original date filters. CSV protects user text from formula execution while retaining signed numeric values. XLSX uses text cells to preserve exact decimal strings beyond spreadsheet numeric precision and never creates formula cells. No fictional double-entry journal is generated.
